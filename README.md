# Birklik.az — мобильное приложение

Приложение на Expo для той же площадки, что и сайт [birklik.az](https://birklik.az).
Firebase-проект **общий с вебом** (`birklik-65289`): те же данные, те же правила, те же
облачные функции. Веб-репозиторий — `Birklik.az`, ветка `next-migration`.

## ⚠️ Expo Go не подходит

В проекте включён **App Check в режиме enforcement** — и на Firestore, и на аутентификации.
Запрос под публичным API-ключом без действительного токена App Check возвращает 401.

Выдать такой токен умеет только нативный клиент (`@react-native-firebase`) через Play
Integrity на Android и App Attest на iOS. Веб-версия SDK получает его через reCAPTCHA, а она
работает исключительно в браузере.

Нативных модулей Firebase в Expo Go нет, поэтому разработка идёт на **собственной сборке**:

```bash
npx expo run:android      # первая сборка долгая, дальше быстро
npm start                 # дальше обычный цикл разработки
```

## Что уже сделано

```
каркас            expo-router, SDK 57, React Native 0.86
оформление        src/theme/theme.ts — 52 токена перенесены из base.css сайта
Firebase          src/lib/firebase.ts — auth, firestore, storage + App Check
идентификаторы    az.birklik.app на обеих платформах
```

`az.birklik.app` — **не новое имя**. Ровно с этим идентификатором в Firebase уже
зарегистрировано Android-приложение (от удалённой обёртки Capacitor), там настроен FCM.
Приложение переиспользует ту регистрацию, `google-services.json` от неё же.

## Настройка перед первым запуском

`google-services.json` в репозиторий не коммитится. Скачать из консоли Firebase:
**Project settings → Your apps → Android `az.birklik.app`** — и положить в корень.

Для App Check в отладочной сборке нужен зарегистрированный debug-токен. При первом запуске
он печатается в консоль; внести его в **Firebase → App Check → Apps → Manage debug tokens** и
положить в `.env`:

```
EXPO_PUBLIC_APPCHECK_DEBUG_TOKEN=...
```

Без этого приложение покажет «Не удалось подключиться к серверу» — и это правильное
поведение, а не поломка: без App Check ни один экран с данными всё равно не откроется.
